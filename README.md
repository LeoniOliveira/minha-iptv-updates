# Minha IPTV — atualizações

Canal público de atualizações e APK genérico para Android 8.0 ou superior.

[Baixar a versão mais recente](https://github.com/LeoniOliveira/minha-iptv-updates/releases/latest/download/Minha-IPTV-1.1.0.apk)

O APK genérico não contém conta, lista nem acesso pessoal. Configure seu próprio acesso Xtream em Conta. Instale atualizações sobre a versão existente para preservar seu acesso e suas listas.

A partir da versão 1.1, o aplicativo verifica novas versões ao abrir o catálogo, com intervalo de seis horas, e oferece verificação manual em Conta. O download exige uma ação sua; o Android pede confirmação de instalação. As atualizações conferem SHA-256, pacote, versão e certificado.

Este repositório contém somente informações de distribuição. Código-fonte, chaves de assinatura e variantes pessoais não são publicados aqui.
